# Agents in Production — NeurIPS 2026 Expo Panel

Single-page site for the panel "Agents in Production: Evals, Harnesses, and the Reinvention of Recommendation" (Sunday, December 6, 2026, Parkside 2, ICC Sydney).

Everything is in `index.html`; images in `assets/`. The Slido embed reads its event code from the `data-code` attribute on the `#slido` element.

Preview: `python3 -m http.server 8792` and open http://127.0.0.1:8792/.
